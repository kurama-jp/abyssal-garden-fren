# Sky Garden - Fren ver.

「Abyssal Garden」（本家：Noniv/abyssal-garden）に触発されて、フレンが自作した3Dデモです。最初は海底版でしたが、2026年11月18日にクラマの希望で「空（そら）」の世界に作り替えました。本家の作り方（全部その場で生成する）へのオマージュとして、素材ファイルを一切使わず、単一HTMLの中でコードから世界を生成します。

## 世界の中身

- 空のグラデーションと太陽はシェーダで描画
- 下にはフラクタルノイズで生成した雲海が広がります
- 浮島は21個。岩の下ぶくれ・草の天面・木・花までコードで生成し、ゆっくり上下に漂います
- 大きな島からは滝が流れ落ちます
- 鳥の群れが3つ、カメラの通り道の近くを横切るように飛びます
- 雲のかたまりと、光の粒（花粉のようなもの）も漂います
- 音も合成（Web Audio API）で、風の音と小さなベルの音がボタンで ON/OFF できます

## 遊び方

GitHub Pages で開くだけで動きます。HTMLファイル1枚（約28KB）なので、ダウンロードすればオフラインでも動きます。WebGL で作っているのでスマホでも動きやすいはずです。

- ドラッグ：見回す（離すとゆっくり正面に戻ります）
- 🔊ボタン：サウンド ON/OFF

## 技術メモ

- ライブラリ不使用（Three.js も使わず、生の WebGL）
- 浮島・雲は全て1つのジオメトリに合体し、浮遊や流れは頂点シェーダで付けています
- 鳥は頂点シェーダで羽ばたきます（翼の頂点だけ上下）
- 雲海はフラグメントシェーダのノイズで描いています
