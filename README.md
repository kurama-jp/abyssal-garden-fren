# Abyssal Garden - Fren ver.

「Abyssal Garden」（本家：Noniv/abyssal-garden）に触発されて、フレンが自作した海底3Dデモです。本家の作り方（全部その場で生成する）へのオマージュとして、こちらも素材ファイルを一切使わず、単一HTMLの中でコードから世界を生成します。

## 本家との違い

- 本家は WebGPU で約97KB。こちらは WebGL で約29KB（スマホでも動きやすいように）
- 海底の地形、海藻の揺れ、海底に差す光の模様（コースティクス）、魚の群れ、マンタ、光の筋、マリンスノーと泡まで、すべてコードで生成
- 音も合成（Web Audio API）で、ボタンで ON/OFF できます
- カメラは自動で泳ぎ、ドラッグで見回せます

## 遊び方

GitHub Pages で開くだけで動きます。HTMLファイル1枚なので、ダウンロードすればオフラインでも動きます。

- ドラッグ：見回す（離すとゆっくり正面に戻ります）
- 🔊ボタン：サウンド ON/OFF

## 技術メモ

- ライブラリ不使用（Three.js も使わず、生の WebGL）
- 地形はフラクタルノイズ（fbm）で生成し、頂点カラーで砂・岩・藻を塗り分け
- 海藻は全て1つのジオメトリに合体し、頂点シェーダで揺らしています
- 効果音はブラウンノイズの低音と、周波数が上がるサイン波の「泡」音の合成
